# Prebuilt Artifacts

This directory is a **build output staging area** for `edgerouter-binaries`.

When building packages locally or in CI, finished artifacts (binaries and installable
archives) are placed under `prebuilt/` and organized by CPU architecture and package name.

**Contents of this directory are generated and are not committed to the Git repository.**
End users should download binaries from the GitHub Releases page instead.

---

## Directory Layout

```
prebuilt/
├── mips32/
│   └── <package>/
│       ├── binaries…
│       ├── <package>-<version>-edgerouter-mips32.tar.gz
│       └── checksums.sha256
└── mips64/
    └── <package>/
        ├── binaries…
        ├── <package>-<version>-edgerouter-mips64.tar.gz
        └── checksums.sha256
```

- The top level is **CPU architecture** (`mips32`, `mips64`)
- Each package has its own subdirectory
- Archives produced here are suitable for upload to GitHub Releases

---

## Architectures

| Tag    | Meaning                | Typical Devices            |
|--------|------------------------|----------------------------|
| mips32 | 32‑bit MIPS EdgeRouter | ER‑Lite, ER‑PoE, ER‑X     |
| mips64 | 64‑bit MIPS EdgeRouter | ER‑4, ER‑6P, ER‑8         |

All binaries are built specifically for **Ubiquiti EdgeRouter devices running EdgeOS**.

---

## Notes

- Binaries are statically linked with **musl** to avoid runtime dependency issues on EdgeOS.
- The contents of this directory may be safely deleted at any time and regenerated by rebuilding.
- This directory exists to provide a predictable output path for builds and CI workflows.
